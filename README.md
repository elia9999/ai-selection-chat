# AI 划词助手

一个轻量级的桌面 AI 对话框：**划词对话、读取剪切板、固定于屏幕**。

纯 Python 标准库实现（tkinter + urllib + ctypes），**不需要安装任何第三方依赖**，单目录、绿色便携。

## 功能

- **划词模式（仿有道浮窗）**：点顶栏「划词」开启划词模式，之后在任意程序（浏览器、文档、聊天软件等）里用鼠标选中文字（拖选或双击），松手即自动在鼠标旁弹出浮窗，可一键「翻译 / 解释 / 总结 / 润色 / 问答」；主窗口全程不隐藏、不闪屏。按 Esc、点 ✕ 或点击其他位置即可关闭浮窗。
- **读取剪切板**：点击「剪切板」按钮，把剪切板中的文本一键放入输入框。
- **上传参考文件**：点击「上传」选择本地文件（可多选），支持 **PDF、Word（.docx）** 以及 txt/代码/JSON/CSV 等文本文件，文件内容会作为参考提供给 AI，之后的提问都会带上；不再需要时点「清除参考」。
- **固定于屏幕**：点击「固定」按钮让窗口置顶显示，窗口位置和大小会被记住，下次启动自动恢复。
- **自定义接口**：兼容 OpenAI Chat Completions 格式的任意服务（OpenAI、DeepSeek、Kimi、Qwen 等），地址、密钥、模型都在设置里改。
- 暗色界面、Enter 发送 / Ctrl+Enter 换行、全局热键可换、无需托盘即可隐藏运行。

## 运行要求

- Windows 10 / 11
- Python 3.8 及以上（标准安装自带 tkinter，无需额外配置）

## 快速开始

1. **直接双击 `AI划词助手.exe`** 即可运行（已打包，无控制台窗口、无需安装 Python）；源码模式下用 `start.bat`（后台运行）或 `start_debug.bat`（带日志）。
2. 点击窗口右上「设置」，填写：
   - **API 地址**：例如 OpenAI 用 `https://api.openai.com/v1`，DeepSeek 用 `https://api.deepseek.com/v1`
   - **API Key**：你的密钥
   - **模型**：例如 `gpt-4o-mini`、`deepseek-chat` 等（与接口匹配）
3. 点「测试连接」确认可用，然后「保存」。
4. 两种划词方式任选：
   - **划词模式（推荐）**：点顶栏「划词」开启（按钮变亮），去其他窗口用鼠标选中文字，松手即弹出浮窗；
   - **热键**：选中文字后按全局热键（默认 Ctrl+Alt+Space）。
   浮窗上点「翻译 / 解释 / 总结 / 润色」：回到主窗口并直接执行（润色会把内容改写为学术英语）；点「问答」：划词内容加入对话，输入问题即可。

## 打包为 exe

- 双击 `build.bat` 即可生成 `AI划词助手.exe`（首次需先运行 `pip install pyinstaller`）。
- exe 为单文件、无控制台窗口模式；配置 `config.json` 仍然保存在 exe 旁边，升级时复制新 exe 覆盖即可保留配置。
- 提示：单文件 exe 启动时会解包到临时目录（首次约 1-2 秒），个别杀毒软件可能对 PyInstaller 单文件误报，加入信任即可。

## 迁移到 macOS（思路）

程序已经按平台做了分层：所有 Windows 专属能力（剪切板、全局热键、全局鼠标监听、按键模拟、窗口外观）都集中在 `win_platform.py` 一个文件里，界面逻辑在 `main.py` 中不依赖平台。

迁移到 macOS 时只需重写 `win_platform.py`，保持函数名和类名不变：

| Windows 实现 | macOS 替代方案 |
| --- | --- |
| ctypes 读写剪切板 | `pyperclip`（读写）+ `NSPasteboard.changeCount`（检测复制变化，pyobjc） |
| RegisterHotKey 全局热键 | `pynput` 键盘监听，或 Quartz EventTap |
| 低层鼠标钩子（划词模式） | `pynput` 鼠标监听，拖选/双击逻辑与现有一致 |
| SendInput 模拟 Ctrl+C | `pynput` Controller 按 Cmd+C |
| 深色标题栏 / DPI 感知 | 无需处理（macOS 原生标题栏） |

其余部分基本不用动：tkinter 跨平台，字体已自动切换为苹方（PingFang SC）；API 对话、配置、浮窗、主界面逻辑完全通用。打包时用 PyInstaller 生成 `.app`。注意 macOS 需要在「系统设置 → 隐私与安全性 → 辅助功能」中授权本程序，全局监听才能工作。

## 配置文件

程序目录下的 `config.json` 保存全部配置（首次运行自动生成），也可直接编辑后重启生效：

```json
{
  "api": {
    "base_url": "https://api.openai.com/v1",
    "api_key": "",
    "model": "gpt-4o-mini",
    "temperature": 0.7,
    "timeout": 120
  },
  "hotkey": "Ctrl+Alt+Space",
  "topmost": false,
  "system_prompt": "你是一个简洁、可靠的 AI 助手，请用中文回答。",
  "window": {"width": 480, "height": 680, "x": null, "y": null}
}
```

## 常见问题

- **热键没反应**：可能被其他程序占用，在「设置」里换一个组合即可。
- **划词抓不到内容**：部分以管理员权限运行的程序（如管理员身份打开的浏览器/终端）会拦截普通权限的模拟按键。请同样以管理员身份运行本程序，或改用「剪切板」按钮手动粘贴。
- **Ctrl 键异常/卡住**：程序模拟 Ctrl+C 时会先检测你是否正按着 Ctrl，不会强行覆盖你的按键状态；若仍异常，重启程序即可恢复。
- **接口报错**：检查 API 地址末尾是否正确（需要 `/v1` 或对应前缀）、密钥是否有效、模型名是否与接口匹配。
- **剪切板内容**：划词过程会临时借用剪切板，结束后自动恢复原内容；个别占用剪切板的软件（如剪贴板管理器）可能干扰，属正常现象。
- **隐私提示**：API Key 明文保存在本地 `config.json`，请勿分享该文件；对话内容会直接发送到所配置的接口服务。
